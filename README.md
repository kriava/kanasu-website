# Kanasu — Sunita Avadhani

Personal editorial website for Sunita Avadhani, based in Brisbane, Queensland, Australia.

## Website

The static site is in `public/` and is configured for GitHub Pages at `https://kanasu.com.au`. GitHub Actions deploys the `public/` folder whenever a commit reaches `main`. `public/CNAME` selects the apex domain; DNS will need to point `kanasu.com.au` to GitHub Pages before the custom domain works.

## Content editor

`.pages.yml` configures Pages CMS collections for Sunita's profile, writing, photo albums and social links. After the repository owner installs the official Pages CMS GitHub App for this repository, editors can add material through `https://app.pagescms.org/`. The editor is an external hosted service and needs the owner to grant repository access. Instructions are at `/editor/`.

All content and media in the public GitHub repository can be viewed or downloaded by anyone. Only publish material Sunita has approved. Do not upload passwords, private contact lists, or personal records.

## When Sunita's details are ready

- Add her approved portrait through the Site Profile collection.
- Add Facebook, Instagram and LinkedIn profile URLs; those links stay hidden until entered.
- Add stories and travel notes through Journal Stories and mark them published when ready.
- Add photo albums with captions and place names through Photo Albums.
- The place hub is ready for Brisbane, Queensland, Sirsi, Karnataka, India, Melbourne, Sydney and Australia stories.

The Trip Spark on the homepage is an offline, rules-based inspiration tool. It asks only for a destination and travel mood, sends nothing to an AI provider, and does not store visitor choices.
