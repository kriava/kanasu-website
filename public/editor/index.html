Update Kanasu

Add stories and photos in a guided editor. New material is published to the public website after it is saved.

01

Connect the editor

Open Pages CMS, sign in with the GitHub account that owns the Kanasu repository, and install its GitHub App for that repository.

02

Add your material

Use Journal Stories for writing and cover photos, Photo Albums for multiple images, and Site Profile for the biography, portrait and chosen social profile links.

03

Publish with care

Save the approved material. GitHub Pages deploys the update. Only upload photos you have permission to share, and never store passwords or private records in the public repository.

Public website reminder

Pages CMS is an external editing service. Its GitHub App must be installed by the repository owner; this project does not grant that access. Everything published to this website and its public repository can be read or downloaded by anyone.
